# Implementation of Shor's Algorithm
In this project, we have implemented the Quantum Fourier Transform (QFT), Quantum Phase Estimation (QPE), and Shor's algorithm. We have benchmarked our code Qiskit implementations, and successfully manage to factorize 15 and 21.

## File structure
 The implementations of QFT and QPE can be found in `qft.py` and `phase_estimation.py`. In `qiskit_implementations.py`, you can find helper functions that set up the QFT and QPE using Qiskit. Our implementation of Shor's can be found in `shors.py`. It can either our implementation of QPE or Qiskit's QPE as a subroutine - which QPE implementation to use is sent in as an argument to the function.

Our plots have been generated by the different scripts in the `/analysis/` folder. Eg `analysis/validate_qft.py` can be run as (for instance)
```
python -m analysis.validate_qft
```
